# Practical Post-Training and Inference Optimization in Large Language Models

A practical guide and implementation resource for post-training techniques and inference optimization strategies for Large Language Models (LLMs).

## Topics Covered

- **Post-Training Techniques**
  - Supervised Fine-Tuning (SFT)
  - Reinforcement Learning from Human Feedback (RLHF)
  - Direct Preference Optimization (DPO)
  - Reward Modeling

- **Inference Optimization**
  - Quantization (INT8, INT4, GPTQ, AWQ)
  - KV Cache optimization
  - Speculative Decoding
  - Continuous Batching
  - Flash Attention

- **Serving & Deployment**
  - vLLM, TGI, TensorRT-LLM
  - Latency vs. throughput trade-offs
  - Hardware-aware optimization
